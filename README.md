 An animated and sound effects-based fun keyboard shortcut quiz game developed for students and children.
 # ⌨️ Keyboard Heroes: Super Final 🥕

A web-based interactive **keyboard shortcuts competition game** designed for IT lessons or fun activities. It features an animated and sound-based system for fierce competition between classroom groups (Fancy 🎀, Cool 🕶️, Fast ⚡).

## 🚀 Features
* **7 Different Stages:** Warm-up, Speed ​​Round, Scenario Round, Browser Round, True/False, Missing Key, and Final Task.
* **Teacher Control Panel:** Time setting can be dynamically changed (5-60 seconds).
* **Visual and Audible Feedback:** Retro sound effects, countdown alerts, and confetti animations generated with the Web Audio API.
* **Live Score Tracking:** The rabbits of groups that answer questions correctly move towards the carrot at the finish line.

## 🛠️ Technologies Used
* HTML5 / CSS3 (Custom Properties & Flexbox)
* Pure JavaScript (Vanilla JS)
* [Animate.css](https://animate.style/) (For animations)
* [Canvas-Confetti](https://github.com/catdad/canvas-confetti) (For celebration effects)

## 🎮 How to Play?
1. Open the game in your browser.
2. Set the time per question from the top panel.
3. Move your rabbit forward by clicking the button (G1, G2, G3) of the group that answered the question correctly.
4. Declare the champion when all stages are finished!
